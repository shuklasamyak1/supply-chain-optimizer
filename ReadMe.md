# 📦 Global Supply Chain Risk & Operational Optimizer

An interactive supply chain decision-support dashboard built with **Python**, **Streamlit**, **Pandas**, and **Plotly**. 

### Key Features
- **OTIF & Fulfillment Tracking:** Monitors On-Time In-Full metrics, late shipment durations, and defect rates across global suppliers.
- **Financial Disruption Risk:** Dynamic modeling of late delivery penalties and defect write-offs.
- **Lead-Time Volatility Modeling:** Histogram and box-plot distributions across multimodal logistics (Air, Ocean, Rail, Courier).
- **Safety Stock Simulation Engine:** Live dynamic inventory buffer and Reorder Point (ROP) calculations using statistical variance ($\sigma_L$ and $\sigma_D$) and $Z$-score service levels.
- **Data Export Center:** Audit tables and one-click CSV export for downstream analysis.

### Tech Stack
- Python 3
- Streamlit
- Pandas, NumPy, Plotly
